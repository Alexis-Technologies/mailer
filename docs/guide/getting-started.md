# Getting Started

::: warning Work in progress
@alexify/mailer is being designed. The package can be installed, but `createMailer` is a
placeholder that throws `createMailer is not implemented yet`.
:::

## Installation

```bash
pnpm add @alexify/mailer
# or
npm install @alexify/mailer
```

Node.js 22 or newer. The package has no runtime dependencies.

## Importing

```js
const { createMailer } = require('@alexify/mailer');
```

```js
import { createMailer } from '@alexify/mailer';
```

See [Why @alexify/mailer?](/guide/why) for what the library is built to do, and the
[API](/api/exports) for the current exports.
